# Echo Briefing Feed

`feed.json` is an Amazon Alexa Flash Briefing feed carrying a weekday morning
market briefing (index futures, premarket movers, 10-year Treasury yield).

Updated automatically every weekday morning. Point a Flash Briefing skill's
feed URL at:

```
https://cdn.jsdelivr.net/gh/craybutts/echo-briefing@main/feed.json
```
